# 🎯 Mine vs Rock Classification using Machine Learning

This project is a simple machine learning classifier that predicts whether an object is a mine or a rock based on sonar data. It demonstrates the application of basic ML concepts like data preprocessing, model training, and evaluation using Python and scikit-learn.

---

## 📌 Problem Statement

The goal is to classify sonar returns from objects on the ocean floor into two categories:
- Mine (metallic object)
- Rock (natural object)

This is a binary classification task using supervised learning.

---

## 📚 Dataset

- Name: Sonar Dataset  
- Features:** numerical features  
- Target: 'M' (Mine) or 'R' (Rock)

---

## ⚙️ Technologies Used

- Python 🐍
- NumPy
- Pandas
- scikit-learn (SVM / Logistic Regression / etc.)
- Google Colab

---

## 🚀 Workflow

1. Import the dataset
2. Explore and preprocess the data
3. Split the data into training and test sets
4. Train the model using a classifier (e.g., SVM)
5. Evaluate the model (accuracy, confusion matrix)
6. Make predictions on new input

---

## ✅ Model Used

- Support Vector Machine (SVM)
- Chosen for its effectiveness in binary classification tasks
- Tuned with parameters
---

## 📊 Accuracy

- Achieved accuracy: 
85% on test data
